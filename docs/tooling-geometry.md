# Каноническая геометрия оснастки

Модуль `src/tooling/` реализует 23 позиции оснастки сварочного стола. Исходные 34 кандидата прошли повторный отбор: плазменные ламели/модуль, пресс, отдельный вращатель и прочие изделия вне стола исключены. ID исключённых изделий не переиспользуются. Листовые детали используют `Contour`, `Hole` и `Slot` из `src/geometry.ts`.

## Публичный API

Импортировать только из `src/tooling/index.ts`:

```ts
import {
  TOOLING_IDS,
  toolingCatalog,
  getToolingEntry,
  createToolingConfig,
  validateToolingConfig,
  buildToolingAssembly,
  buildDefaultToolingAssembly,
  validateToolingAssembly,
  assertToolingAssembly,
  assertA10B08Compatibility,
  buildSheetBom,
  estimatePartMassKg,
} from './tooling/index.js'
```

Основные типы: `ToolingId`, `ToolingCatalogEntry`, `ParameterDefinition`, `ToolingConfig`, `SheetPart`, `ToolingAssembly`, `AssemblyTransform`, `AssemblyInstance`, `AssemblyJoint`, `PurchasedComponent`, `SheetBomItem`, `ValidationResult`.

### Каталог и параметры

`toolingCatalog` и `TOOLING_IDS` имеют устойчивый порядок без перенумерации исключённых ID. У каждого параметра есть:

- `key`, `label`;
- `type`: `number`, `boolean` или `enum`;
- `unit`: `mm`, `deg`, `count` или `none`;
- `default`;
- для числа — `minimum`, `maximum`, `step`;
- для перечисления — `options`.

`createToolingConfig()` не пропускает неизвестные поля, `NaN`/`Infinity`, значения вне диапазона и дробные количества. У изделий без посадочного зазора параметр `clearance` больше не показывается; ранее сохранённое значение игнорируется при загрузке.

```ts
const config = createToolingConfig('B01', {
  length: 600,
  width: 250,
  height: 200,
  thickness: 6,
  holeDiameter: 16,
  holePitch: 50,
  gridMargin: 50,
  mountDiameter: 16,
  mountPitch: 50,
  radialRadius: 70,
})

const assembly = buildToolingAssembly(config)
```

Для короткого вызова:

```ts
const stop = buildDefaultToolingAssembly('A01', {
  length: 420,
  slotLength: 240,
})
```

## Контракт сборки

`ToolingAssembly` содержит:

- `parts`: канонические плоские детали с количеством, материалом, толщиной, плотностью, отверстиями, пазами и native-контурами;
- `instances`: один экземпляр на каждую физическую деталь;
- `sheetBom`: листовая спецификация, сгруппированная строго по материалу и толщине, с количеством и оценочной чистой массой;
- `purchased`: покупные узлы с количеством и параметрами интерфейса; всегда `excludedFromSheetNesting: true`;
- `joints`: парные интерфейсы реальных стыков;
- `warnings`: предметные ограничения расчёта/испытаний.

Единицы геометрии и перемещений — миллиметры. Вращения задаются в градусах. Порядок всегда `XYZ`: сначала локальный X, затем Y, затем Z, после чего применяется перенос. Этот порядок уже учтён валидатором стыков.

```ts
const result = validateToolingAssembly(assembly)
if (!result.valid) {
  console.error(result.issues)
}
assertToolingAssembly(assembly) // бросает Error с путями всех дефектов
```

Валидация проверяет положительность/конечность размеров, количество, замкнутость и самопересечения native-контуров, вырожденные сегменты, выход отверстий/пазов за габарит, минимальную перемычку 2 мм, столкновения отверстий/пазов/внутренних вырезов, количество экземпляров, ссылки стыков и совпадение их координат, осей и размеров после `AssemblyTransform`.

Перемычка 2 мм — нижняя геометрическая блокировка ядра, а не разрешение конкретному лазеру. Реальный минимум назначает изготовитель по материалу, толщине и станку.

## B01 — утверждённая компоновка

B01 строится ровно из:

1. одной перфорированной верхней полки;
2. двух боковин;
3. одного монтажного торца с замкнутым радиусным вырезом.

Низ и дальний торец отсутствуют. Верх соединён с боковинами шестью параметрическими шип–паз интерфейсами, монтажный торец приварен к боковинам. Радиусный паз состоит из native `ARC + LINE + ARC + LINE`, а не из линии гравировки.

`mountDiameter` и `mountPitch` задают вводимый монтажный рисунок. Сборка не объявлена универсально совместимой: перед изготовлением отдельно проверяются реальная стенка стола, доступ с обратной стороны и рёбра.

## Сменные элементы

A10 и B08 проверяются до объединения корзины:

```ts
const insert = createToolingConfig('A10', {
  holderPitch: 80,
  holderDiameter: 10,
  profile: 'vee',
  profileSize: 60,
  veeAngle: 90,
})
const holder = createToolingConfig('B08', {
  insertPitch: 80,
  insertDiameter: 10,
})
assertA10B08Compatibility(insert, holder)
```

Проверяются шаг и проход крепежа, толщина, габариты, угол и рабочий V-профиль. B08 включает два собственных вкладыша; отдельная строка A10 в корзине означает дополнительные сменные вкладыши. Радиусный A10 нельзя выдавать за штатный V-вкладыш B08.


## Полный состав каталога

- A01 прямой регулируемый упор; A02 плоский угловой; A04 эксцентриковый упор; A05 переходная плита; A06 соединительная планка; A07 планочный прижим; A09 прокладки; A10 сменные вкладыши V-ложемента; A12 держатель горелки на краю стола.
- B01 прямой блок расширения; B02 угловой блок расширения; B03 мостовой блок; B04 угловой упор с косынками; B05 коробчатый угловой упор; B06 трёхплоскостной угловой упор; B07 коробчатая проставка; B08 V-ложемент; B10 прижимной портал на столе; B11 модуль для тисков.
- C01 покупной фиксирующий штифт с необязательным адаптером; C02 адаптер быстрозажима; C03 направляемый винтовой упор; C04 роликовая опора трубы на столе.

C01 при `includeAdapter: false` не создаёт листовую имитацию штифта. C02–C04 явно перечисляют покупные механизмы и их интерфейсные размеры; они не попадают в `parts` и `sheetBom`. Архив содержит отдельные `assembly-notes.txt`, `assembly-transforms.json` и спецификацию покупных компонентов. Старые проекты с исключёнными ID отклоняются целиком с указанием ID; браузер не перезаписывает прежнее автосохранение до изменения корзины пользователем.

## Масса и материалы

Плотности в кг/мм³:

- S235JR, S355JR: `7.85e-6`;
- AISI304: `7.93e-6`;
- AlMg3: `2.66e-6`.

`estimatePartMassKg()` вычитает площади внутренних контуров и круглых отверстий из наружного контура. `buildSheetBom()` не смешивает разные материалы или толщины.

## Граница готовности

Модуль выдаёт проверенную параметрическую геометрию и схему сборки, но не назначает допустимую нагрузку. Для B03, B10, B11 и C03–C04 обязательны отдельные расчёт пути нагрузки и испытания под выбранные покупные узлы. Лазерная кромка не наследует точность фрезерованных заводских аналогов.

Перед первым комплектом нужен пробный образец шипов/пазов и отверстий на фактическом листе. `clearance` — зазор сопряжения; компенсация ширины реза остаётся в CAM и не должна добавляться повторно.
